Evaluation Framework

ChemEval is organized as a progression from core chemical knowledge to literature assimilation, molecular understanding, and high-level scientific deduction.

1

Advanced Knowledge Question Answering

Objective and subjective chemistry QA covering terminology, concepts, quantitative analysis, and cross-modal reasoning.

Objective QA Subjective QA 15 tasks
2

Literature Understanding

Reading and extracting information from chemical papers, then generating abstracts, outlines, topics, and reaction-type judgments.

Information Extraction Inductive Generation 19 tasks
3

Molecular Understanding

SMILES/IUPAC conversion, molecular property prediction, and molecular description from structures, spectra, and text.

Name Translation Property Prediction 15 tasks
4

Scientific Knowledge Deduction

Retrosynthesis, reaction condition recommendation, reaction outcome prediction, and mechanism analysis for chemical synthesis.

Retrosynthesis Reaction Mechanisms 13 tasks

Benchmark Construction

The benchmark combines open-source chemical datasets with expert-authored materials, then filters, audits, formats, and converts them into task-specific Q&A sets.

Empirical Readout

ChemEval is designed to reveal where current general, chemistry-specific, reasoning, and multimodal models succeed or fail in chemistry.

General LLMs

Strong at literature understanding and instruction following, but weaker on deep molecular understanding and scientific inference.

Chemical LLMs

Often better on technical chemistry tasks such as terminology and molecular properties, while showing limitations in broad language behavior.

Future Direction

Scaling and few-shot prompting are useful but insufficient; stronger chemical AI needs domain tools, simulation, and multimodal grounding.

Code And Data

This repository provides answer extraction, LLM-based grading, and code-based metric scripts for textual and multimodal ChemEval tasks.

Textual Evaluation

Use Textual/code evaluate/ for deterministic metrics and Textual/LLM evaluate/ for LLM-based grading.

python "Textual/code evaluate/1_Split_filename.py"
python "Textual/code evaluate/2_Extract.py"
python "Textual/code evaluate/3_Evaluate.py"

Multimodal Evaluation

Use Multimodel/ for multimodal prompt preparation, LLM-based processing, and code-based evaluation.

python "Multimodel/3_code_evaluate/1Extract.py"
python "Multimodel/3_code_evaluate/2Evaluate.py"
